# SOLVAR — обновление 26.10.2026

## Изменения

- В админку добавлен отдельный пункт «Заказы клиентов».
- Заказы получают последовательный короткий номер `1, 2, 3…`. Номер показывается покупателю, в админке, экспорте и уведомлениях; UUID остаётся внутренним ID.
- Добавлена категория каталога «Сигареты» с маршрутом `/collections/cigarettes`, навигацией на главной и поддержкой импорта CSV; сетка витрин адаптирована под пять категорий на широком экране.
- Текст об оплате установлен в значение «Информация по оплате предоставляется менеджером». Старые сохранённые настройки с прежним текстом нормализуются при выдаче клиентам.
- Подвал показывает только Telegram (если он настроен) и `zakaz@solvar.su`. Ссылки VK/Авито и публичная кнопка «Управление магазином» удалены.
- Ссылка `/admin` сохранена для прямого доступа; видимой ссылки на неё в основном меню и подвале нет.
- В настройках, SEO-метаданных и публичных текстах старое название CHERNOGOR нормализуется до Solvar.

## Обновление существующей базы

1. Сделайте проверенную резервную копию базы.
2. Установите зависимости из корня проекта.
3. Запустите `npm run db:orders` с корректным серверным `.env` и `DATABASE_URL`. Скрипт создаёт новую колонку, выдаёт существующим заявкам номера в хронологическом порядке и инициализирует счётчик для новых заказов. UUID и клиентские данные не заменяются.
4. Выполните `npm run test:technical`, `npm run test:hardening`, `npm run typecheck` и сборку согласно `DEPLOYMENT-RUNBOOK.md`.
