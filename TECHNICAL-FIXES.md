# SOLVAR — технические исправления

## Подтверждённые проблемы и исправления

1. **Выдача статики на Windows.** Проверка `filePath.startsWith(dist + "/")` не подходит к путям Windows с обратным слешем. Вместо строкового префикса используется `path.relative` с контролем выхода за пределы папки. Добавлено отклонение обратных слешей и NUL в URL. Нативные статусы 400/403/404/405 и обработка HEAD сохранены.
2. **Побочные записи при ошибке первичной инициализации.** В `seed.ts` проверка обязательных учётных данных перенесена перед вставками. Проверено на отдельной пустой SQLite: при отсутствии данных администратора таблицы остаются пустыми.
3. **Небезопасная dev-конфигурация.** Убрано `allowedHosts: true`; теперь применяется штатная проверка хостов Vite. Это не изменение разрешённых origin авторизации и не отключение защиты браузера.
4. **Стабильность путей в сборщике.** Перед определением vendor chunks разделители идентификаторов приводятся к `/`.
5. **Неполная инструкция Windows.** Добавлены `WINDOWS-START.md`, безопасная команда `env:local` и команда `test:technical`. Генератор `.env` не перезаписывает существующие файлы и не выводит секрет в терминал. Отключает только внешний фоновый отправитель в НОВОМ локальном окружении.
6. **Устаревшая ссылка в README.** Ссылка на отсутствующий отчёт заменена ссылкой на этот файл, а подробная инструкция Windows вынесена отдельно.

## Проверки

- Исходная сборка и исходный TypeScript уже проходили; выдуманные ошибки сборки не заявляются.
- После исправлений: `npm run test:technical` — **24/24**, включая Windows/POSIX-пути, соседнюю папку с похожим именем, другой диск, traversal, некорректные URL и повторный запуск генератора `.env`.
- `npm run build --workspace=@template/web` — TypeScript и Vite успешно.
- Отдельная проверка TypeScript — успешно.
- 10 HTTP-проверок реального локального Bun-сервера: PNG, favicon, шрифт, JS, HEAD, отсутствующий файл, обход папки, некорректная кодировка и запрещённый метод.
- Дополнительная проверка ранней ошибки инициализации на отдельной временной SQLite — успешно.
- Журналы текущего прогона сохранены в `qa-technical/`. Старые отчёты в других папках относятся к предыдущим редакциям.

## Что НЕ проверялось и не менялось

Проверка ограничена общетехнической совместимостью и защитой: торговые сценарии, оформление заказов, оплата, интеграционные отправки и торговая админка не дорабатывались. Работа на настоящей Windows не проверялась: Windows-пути проверены автоматическими тестами `path.win32`, а сервер запускался в Linux. Внешний production-сервер, Electron и Expo не тестировались. Визуальное оформление не изменено, повторная дизайнерская проверка не проводилась.
