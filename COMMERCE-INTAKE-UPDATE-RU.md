# Изменение приёма заявок SOLVAR — 21.10.2026

## Что изменено

- Удалён прежний жёсткий kill switch дистанционного оформления заказов и все связанные серверные проверки.
- Флаг `documentsReady` сохранён в схеме только для обратной совместимости со старыми настройками, но больше не блокирует включение приёма заявок.
- Из админки убран обязательный юридический чекбокс; переключатель «Включить приём заявок» управляет режимом напрямую. При сохранении legacy-флаг нормализуется в `true`.
- Обновлён устаревший текст страницы каталога, который сообщал, что оформление заказов недоступно.
- Панель обработки заявок, повтор уведомлений и платёжные поля доступны без прежнего kill switch.

## Что намеренно осталось

- Владелец по-прежнему должен включить приём заявок в админке.
- В production CAPTCHA остаётся обязательной по умолчанию. Если она нужна, но ключи Cloudflare Turnstile не настроены, система не даст включить приём заявок и покажет понятную ошибку. Для отключения этой проверки используется существующая серверная настройка `ORDER_CAPTCHA_REQUIRED=false`; не отключайте её без осознанного решения.
- Проверки Origin, honeypot, подписанная cookie устройства, лимиты частоты, проверка состава/цен на сервере, повторная защита и согласие на обработку персональных данных сохранены.
- Возрастной экран не менялся.

## Проверка

Добавлен контрактный тест на отсутствие блокировки по `documentsReady`, отсутствие устаревшего kill switch и сохранение проверки обязательной CAPTCHA. Интеграционные тесты обновлены: legacy-конфигурация `documentsReady=false` больше не должна отклоняться.
