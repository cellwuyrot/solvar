# SOLVAR — состояние релиза (20 октября 2026)

Проверена сборка исходных файлов и доступные автономные технические тесты. Веб-проект использует Bun, React, Vite и libSQL; для полного запуска требуются установка зависимостей, конфигурация `.env`, создание схемы базы данных, работающий сервер и проверка интеграций на целевом хостинге.

## Доступные функции

- Информационный сайт, контакты и политика конфиденциальности.
- Запись на очный визит (включается отдельно в конфигурации визитов через администратора; после первоначальной настройки БД).
- Административный интерфейс, включая управление визитами.
- Валидация формы: неверная, прошедшая или слишком далёкая дата сопровождается явной ошибкой.

Каталог табачной продукции, корзина, дистанционные заявки на товары и резервирование **не активированы**. Публикация каталога и приём заказов не входят в проверенный функционал этого релиза.

## Запуск

Следуйте `WINDOWS-START.md` для локального запуска или `DEPLOYMENT-RUNBOOK.md` для публикации. Не загружайте рабочие пароли в архив. Перед публичным запуском проверьте HTTPS, конфигурацию защиты от ботов, обработку персональных данных, резервное копирование и работу всех подключённых уведомлений.

## Проверка

`npm run test:technical` — автономные тесты. Для полной проверки приложения также нужны `npm ci`, `npm run build:web`, тестовый запуск Bun-сервера и проверка записи через браузер со специально созданной тестовой базой. Без этих шагов нельзя считать работу приложения в production подтверждённой.
