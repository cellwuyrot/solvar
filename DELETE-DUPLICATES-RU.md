# Удаление повторяющихся товаров по названию

Админка → Каталог товаров / Авторские наборы → «Удалить дубли по названию» → «Найти дубли» → просмотр списка → «Удалить дубли» → подтверждение.

Совпадение: Unicode NFKC, без учета регистра, пробелов по краям и повторных пробелов. Один товар сохраняется в каждой группе (приоритет у используемого в наборах, затем у товара с изображением, затем активного, затем по ID). Если два или более экземпляра используются в наборах, группа не удаляется автоматически. Предварительный просмотр указывает сохраняемые/удаляемые ID. При изменении плана удаления между просмотром и нажатием кнопки операция блокируется. Удаление выполняется в транзакции. Другие поля товаров не объединяются.

Перед удалением сделайте резервную копию базы данных. Удаление необратимо.

Проверка: `node --experimental-strip-types --test tools/tests/product-duplicates.test.mjs` — 6 из 6 тестов успешно. Полноценная сборка и браузерное тестирование здесь не выполнялись (зависимости проекта не установлены).
