# Изменения: заявки через Telegram

## Добавлено
- Серверная модель заявки и интеграции, additive-миграция и команда `npm run db:orders`.
- Приём заявки из корзины без оплаты; проверка актуальной суммы и доступности товара.
- Сохранение заявки до отправки Telegram, защита повторов, статусы доставки уведомлений.
- Административный раздел «Заявки / Telegram»: настройки, тест, список, статусы, ручной повтор.
- Серверный `TELEGRAM_BOT_TOKEN`, помощник `npm run telegram:chat-id` без печати токена.
- Тесты `packages/web/tools/test-orders.ts`; инструкции `TELEGRAM-ORDERS.md`; отчёт `TECHNICAL-REPORT-RU.md`.

## Исправлено
- CORS и Origin-проверка административных запросов.
- Production trusted origins не включают localhost автоматически.
- Полная проверка TypeScript project references и совместимость Vite-плагинов.
- Целые количества в сохранённой корзине, округление денежных сумм, мобильная прокрутка формы.

## Проверки на передаваемом коде
- Полная TypeScript-проверка и web production-сборка прошли.
- Server order tests прошли с имитацией Telegram на временной БД.
- Исходный verify.ts прошёл на тестовой БД: каталог, публичная безопасность, auth, upload, CRUD.
- В локальном браузере пройдены мобильная форма, согласие, сохранение заявки, очистка корзины и админка; ошибок JavaScript не обнаружено.
- Production-сервер запущен локально; health, страницы, robots и sitemap проверены.
- Проверено соответствие npm manifest/lockfile через dry-run npm ci. bun.lock обновлён отдельно; установка по bun.lock не является проверенным путём этой приёмки.

## Не сделано / не подтверждено
- Рабочий сервер не изменён, реальный токен не использовался, живое сообщение в чат владельца не отправлялось.
- Приём оплаты, касса, чеки, Telegram-магазин внутри бота, автоматическая очередь, склад, адресная доставка, роли и полноценная CRM не реализованы.
- Зависимости требуют отдельного security-обновления; наблюдения по SEO, документам и эксплуатации приведены в отчёте.
- Не использована действующая база магазина. В архиве нет .env, локальных БД, node_modules, build-артефактов и тестовых персональных данных.
